# Witcher Access

An accessibility mod that makes The Witcher: Enhanced Edition Director's Cut (version 1.5, Steam or GOG) playable for blind players. It speaks everything through your screen reader, with sound cues for the 3D world, and you play with the keyboard or a game controller.

Mod developer: Lirin's Workshop.

## Download

Get the newest WitcherAccessSetup.exe from the Releases page of this repository and run it. The installer finds the game, lets you choose the language, and installs everything. The manual opens at the end.

## Updates

The mod checks for a new version a few seconds after the game starts. When there is one, it tells you; open the accessibility menu (Ctrl+F8, or Start on a controller) and choose Install update. The game closes, the update installs, and the game starts again. Your settings are kept.

## Changes

What changed in each version is in the release notes, and in WitcherAccess_changelog.txt in the game's System folder.
